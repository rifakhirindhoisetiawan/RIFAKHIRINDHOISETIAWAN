Downloader media dari 16 platform. Kode ada di app-mori/.

Status

Halaman ini masih kerangka. Mori adalah aplikasi pihak ketiga (GitHub, lisensi GPL-3.0) dan belum di-integrasikan ke dashboard ini.

Cara pakai (resmi)

Distribusinya lewat GitHub Releases, bukan dari repo ini:

  • Android — unduh .apk, sideload
  • macOS — unduh .dmg, tarik ke Applications
  • Windows — jalankan -Setup.exe
  • iOS — .ipa via sideload

github.com/coflyn/Mori/releases

Jalan dari browser (lokal)

UI web-nya ada di app-mori/public/. Belum ada backend-nya, jadi jalankan sendiri:

cd app-mori
npm install
npx serve public

Catatan: package.json memanggil node server.js, tapi server.js tidak ikut dalam arsip zip — hanya source yang ada.

Isi arsip

  • public/ — UI web (index.html, css, js scraper)
  • assets/ — ikon & screenshot aplikasi
  • landing/ — halaman landing GitHub Pages
  • android/, ios/ — wrapper Capacitor
  • src-tauri/ — wrapper desktop (Rust)
