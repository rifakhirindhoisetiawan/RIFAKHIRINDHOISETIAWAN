Cara menjalankan

Lakasir adalah aplikasi PHP (Laravel). Halaman ini tidak menjalankan PHP — aplikasinya berjalan di PC lewat Docker, dan halaman ini cuma pintu masuknya.

  1. Buka folder aplikasi di terminal:
    cd D:\CODING\RIFAKHIRINDHOISETIAWAN\RIFAKHIRINDHOISETIAWAN\lakasir-1.x
  2. Jalankan docker compose up -d --build. Pertama kali lama karena harus mengunduh PHP, MySQL, Redis, lalu composer install dan npm run build.
  3. Sebelum pertama kali, kunci dan database perlu disiapkan:
    docker compose exec app php artisan key:generate
    docker compose exec app php artisan migrate --path=database/migrations/tenant --seed
  4. Buka http://localhost di PC.
Halaman ini dibuka dari telepon? localhost artinya telepon itu sendiri, bukan PC. Pastikan telepon satu WiFi dengan PC, lalu tekan tombol Pakai IP PC ini.
