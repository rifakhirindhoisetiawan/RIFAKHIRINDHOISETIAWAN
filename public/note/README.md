# Folder NOTE

Folder ini berisi fitur **Note / Daftar Produk** yang sebelumnya di `note.html` (root).

- **File utama:** `note/note.html` — buka via `note/` dari menu NOTE di `index.html`
- **Alias:** `note/index.html` (copy dari note.html agar `note/` langsung kebuka)
- **Compat:** `note.html` di root masih ada biar bookmark lama tetap jalan
- **Catatan:** file standalone (CSS + JS + data inline, tanpa fetch/import/manifest) jadi aman dipindah tanpa ubah path
